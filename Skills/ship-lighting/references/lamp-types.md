# 灯具型号与参数

## 支持的功率规格

| 型号标识 | 功率 | 光通量 | 默认 |
|:--------:|:----:|:------:|:----:|
| `20W` | 20W | 1800 lm | |
| `30W` | 30W | 3000 lm | |
| `40W` | 40W | 4000 lm | ✅ 默认 |
| `60W` | 60W | 6000 lm | |

## 型号格式

```
{前缀}-P{功率}W-{色温}K
```

例如:
- `LED-P40W-6000K` — LED 面板灯 40W 6000K
- `LED-P20W-4000K` — LED 面板灯 20W 4000K
- `防爆灯-40W-4000K` — 防爆灯 40W 4000K

> 色温后缀不影响计算逻辑，仅作标识。计算引擎通过提取 `{数字}W` 匹配功率和光通量。
